Install Lock In Bro in Chrome

1. Download lock-in-bro-extension.zip.
2. Unzip it and keep the lock-in-bro-extension folder somewhere permanent.
3. Open chrome://extensions in Chrome.
4. Turn on Developer mode (top right).
5. Click Load unpacked.
6. Select the unzipped lock-in-bro-extension folder containing manifest.json.
7. Pin Lock In Bro using Chrome's Extensions menu if you want easy access.
8. Open Lock In Bro, choose websites to block, and start a focus session.
   Grant access to the websites you choose when Chrome asks.

This is a manual installation, not a Chrome Web Store installation.
Keep the folder on your computer while using the extension.

Updating an existing installation:
Replace the files in your current extension folder with the updated ZIP contents,
then click Reload for Lock In Bro at chrome://extensions. Keep the same folder
and installation so Chrome preserves your client ID and saved session recap.
Open the extension to retry syncing its most recent completed session.

Open the dashboard using the link inside the extension to select your history.
If a session is waiting to sync, leave Chrome running while it retries.
